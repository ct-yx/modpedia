## 本次修复重点

AI 完成回答时不再删除正文中的 `[来源: document_id | 标注: ...]`。客户端按 Markdown 行解析引用，把匹配本轮搜索轨迹的来源渲染为正文后的短标注；来源卡片点击仍通过 `ManualSourceNavigator` 跳转，公开 API 不可用时回退来源预览。

仅搜索、模拟会话和旧会话迁移使用同一布局路径。未出现在本轮搜索结果中的文档 ID不会生成跳转按钮，避免模型输出任意路径造成误跳转。

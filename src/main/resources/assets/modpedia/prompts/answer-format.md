## 回答格式

直接用玩家语言回答，优先给结论；操作、配方、材料和前置条件使用编号列表。

来源紧跟被支持的段落，不集中堆在末尾：

`[来源: document_id | 标注: 支持的内容]`

物品使用 `[[item:namespace:path|名称]]`；工具字段和原始 JSON 不出现在面向玩家的正文中。任务回答分为“任务定义”“玩家当前进度”“Wiki 说明”；实时进度未同步时明确写出。

回答末尾使用：

```text
<modpedia_follow_up_questions>
- 与当前实体直接相关的问题
- 一个可执行的补充问题
- 一个针对前置条件、配方或排错的问题
</modpedia_follow_up_questions>
```

# ModPedia 回答格式

```markdown
## 结论

用玩家提问的语言直接回答。

## 操作步骤

涉及操作、配方、材料或前置条件时，使用编号列表；信息缺失时明确列出缺口。

每个结论、步骤、配方或前置条件段落后，紧跟真正支撑该段的来源标注；不要把来源单独集中到回答末尾：

[来源: document_id | 标注: 这份资料支持的内容]

物品、方块和标签优先写成 `[[item:namespace:path|游戏显示名称]]` 或 `[[tag:namespace:path|标签名称]]`；客户端会在普通正文显示本地化名称，并在按住 Ctrl 时显示原始 ID。

如果回答任务问题，单独说明“任务定义”“玩家当前进度”“Wiki 说明”三个部分；没有实时快照时写明未同步。随机奖励必须写成候选列表，不得写成保证获得。
```

只列出 3 到 5 个与回答最相关的来源，不要把所有搜索候选都列出。来源 ID 必须来自本轮 `search_knowledge` 返回的结果，标注用一句短语说明它支持了哪一部分回答。旧式单独的“来源”段落仍可读取，但不作为首选格式。

回答末尾追加三个后续问题，使用客户端协议块，不要把协议标记解释给玩家：

```text
<modpedia_follow_up_questions>
- 与当前实体直接相关的后续问题
- 另一个可执行的补充问题
- 一个针对前置条件、配方或排错的补充问题
</modpedia_follow_up_questions>
```

# ModPedia 助手使用说明

ModPedia 是整合包内的本地模组手册助手。它读取已经安装的模组手册，按完整 Markdown 段落检索资料，再由 AI 根据检索到的来源组织回答；也可以在设置中只使用本地搜索，不调用 AI。

## 开始使用

1. 在游戏中按 **K** 打开或关闭助手浮窗。
2. 在输入框中用自然语言描述你要解决的问题。直接写游戏内显示名称、模组名称或“这个机器”即可；模组 ID、物品 ID 和标签只是可选的精确补充，不需要玩家事先知道。
3. AI 会先调用本地 `search_knowledge` 工具。资料不足时会改写查询继续搜索，最后只引用本轮实际找到的来源。
4. 如果只想查手册，在设置中把工作模式切换为 **仅搜索**。此模式跳过模型请求，直接返回完整 Markdown 段落、标题路径和正文来源标注。

## 查看来源和原手册

回答正文的来源标注区只显示 AI 选出的少量相关来源和用途标注。点击标注可以预览 Markdown；如果对应手册模组在当前客户端提供公开入口，还可以继续跳转到原手册的具体页面。回答末尾的三个按钮是模型预测的后续问题，不是手册跳转按钮。

## 历史、设置和知识库

- **历史**：新建、切换、重命名或删除本地会话。
- **设置**：配置 OpenAI 兼容 API、模型、API Key、流式回答和搜索强度；仅搜索模式不需要 API 配置。
- **F9**：重新扫描已安装模组手册，并更新本地知识库。人工维护的 Markdown 位于 `config/modpedia/knowledge/custom/`，启动时会自动导入 SQLite。

## 怎样提问更容易得到准确答案

不要只问“这个机器怎么用”。可以直接写显示名称，例如：

> 压力管如何连接、设置并防止漏气？请列出前置条件和步骤。

这样 ModPedia 会自动从显示名称、模组语言文件、标签和搜索结果中补充内部检索词，再查找配方、步骤、前置条件和故障排查资料。不同语言的手册可以交叉检索，但资料不足时会明确列出缺口，不把其他模组的相似名称当成确定答案。

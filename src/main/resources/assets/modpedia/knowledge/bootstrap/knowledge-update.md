# 知识库更新说明

首次启动时，ModPedia 会读取当前实例中已安装模组的本地手册资源，并生成 Markdown 文件、清单和关键词索引。

自动生成内容位于 `config/modpedia/knowledge/generated/`，玩家手工补充内容位于 `config/modpedia/knowledge/custom/`。
